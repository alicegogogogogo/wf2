# 数字资源供应链与溯源平台

这是一个面向代码、AI 模型、数据集和构建产物的后端项目基线。项目将逐步形成统一资源图谱，用于资源登记、内容寻址、签名验证、来源追踪、依赖分析与风险治理。

当前基线刻意保持精简，只提供一个可运行的 HTTP 服务和健康检查。制品登记、分块存储、签名、依赖图、SBOM、许可证、漏洞、构建证明、策略准入、晋级撤回、隔离、代理缓存、风险通知和跨仓库解析等能力尚未实现，将在后续任务中按公开需求逐步增加。

## 环境

- Python 3.11 或更高版本
- 当前基线没有第三方运行依赖

## 启动服务

在仓库根目录执行：

```bash
python -m provenance_api --host 127.0.0.1 --port 8000
```

服务监听成功后，可以访问：

```text
GET /health
```

成功响应为 HTTP 200，响应体是 JSON：

```json
{"status":"ok"}
```

其他路径返回 HTTP 404 和 JSON 错误信息。服务可通过 `Ctrl+C` 正常停止。

## 运行测试

```bash
python -m unittest discover -s tests -v
```

## 开发边界

- 新增接口必须在公开文档中说明启动方式、请求和响应行为。
- 持久化数据和生成文件不得提交到 Git。
- 不得把密钥、访问令牌、私有验证脚本或控制系统资料写入仓库。
- 对已有公开接口的更改应保持向后兼容，除非任务明确要求破坏性升级。
