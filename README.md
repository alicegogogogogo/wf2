# 数字资源供应链与溯源平台

这是一个面向代码、AI 模型、数据集和构建产物的后端服务基线。当前版本提供可运行的 HTTP 服务和健康检查。

## 环境

- Python 3.11 或更高版本
- 当前基线没有第三方运行依赖

## 启动服务

在仓库根目录执行：

```bash
python -m provenance_api --host 127.0.0.1 --port 8000
```

服务监听成功后，可以访问：

```text
GET /health
```

成功响应为 HTTP 200，响应体是 JSON：

```json
{"status":"ok"}
```

其他路径返回 HTTP 404 和 JSON 错误信息。服务可通过 `Ctrl+C` 正常停止。

## 资源登记与查询

资源记录用于描述代码、AI 模型、数据集或构建产物，并保留其内容摘要及来源。当前记录仅保存在进程内存中，服务停止后自然清空，不写入任何文件。

### 登记资源

```text
POST /resources
```

请求体必须是一个完整的 JSON 对象，字段如下：

- `name`（必填，非空字符串）：资源名称。
- `category`（必填，字符串）：资源类别，只允许 `code`、`model`、`dataset`、`build-artifact`，大小写无关，存储时归一为小写。
- `digest`（必填，字符串）：64 位十六进制内容摘要，大小写均可，存储时归一为小写。
- `origin`（可选，字符串）：资源来源说明。

不接受其他未知字段。成功时返回 HTTP 201 和新资源（含稳定标识 `id`）：

```json
{"id":"res-000001","name":"llm-7b","category":"model","digest":"abcdef...","origin":"https://example.com/model"}
```

类别、名称与摘要完全相同的重复登记返回 HTTP 409，原记录保持不变。

### 查询资源

```text
GET /resources          # 按创建顺序返回全部资源（空集合为 []）
GET /resources/{id}     # 按标识返回单条资源，未找到返回 HTTP 404
```

标识为空或包含路径分隔符时返回 HTTP 400。查询为只读操作，不改变任何状态。

### 错误响应

资源接口的错误响应均为 JSON：`{"error": "<稳定错误码>", "message": "<说明>"}`。

| 状态码 | 错误码 | 含义 |
| --- | --- | --- |
| 400 | `invalid_json` | 请求体缺失、无法解码或顶层不是 JSON 对象 |
| 400 | `missing_field` | 缺少必填字段 |
| 400 | `invalid_field` | 字段类型错误、名称为空或来源不是字符串 |
| 400 | `unknown_field` | 包含未声明的字段 |
| 400 | `invalid_category` | 类别不在允许的四种之内 |
| 400 | `invalid_digest` | 摘要不是 64 位十六进制字符串 |
| 400 | `invalid_id` | 标识为空或含路径分隔符 |
| 404 | `not_found` | 指定标识的资源不存在 |
| 405 | `method_not_allowed` | 资源路径收到未声明的方法 |
| 409 | `duplicate_resource` | 同类同名同摘要的资源已存在 |

所有资源接口响应均为紧凑 UTF-8 JSON，键顺序稳定并以换行结束。请求无法解析时服务只返回约定状态码与错误信息，不抛出异常、不泄露堆栈细节，也不会留下半条记录。

## 运行测试

```bash
python -m unittest discover -s tests -v
```

## 开发边界

- 新增接口必须在公开文档中说明启动方式、请求和响应行为。
- 持久化数据和生成文件不得提交到 Git。
- 不得把密钥、访问令牌、私有验证脚本或控制系统资料写入仓库。
- 对已有公开接口的更改应保持向后兼容，除非任务明确要求破坏性升级。
- 公开业务接口为健康检查与上述资源登记、查询接口。
